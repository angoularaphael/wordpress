# Formation Développement Web Full Stack - École Convergence

## Présentation

Devenez développeur full stack et maîtrisez les technologies web les plus demandées du marché.

## Objectifs pédagogiques

- **Développement Front-end** : Maîtriser HTML5, CSS3, JavaScript et les frameworks modernes
- **Développement Back-end** : Concevoir et développer des API et bases de données
- **Applications mobiles** : Développer des applications mobiles natives et hybrides
- **DevOps & Cloud** : Déployer et maintenir des applications en production

## Programme détaillé

| Module | Durée |
|-------|-------|
| Front-end : HTML5, CSS3, JavaScript | 140h |
| Framework Front-end (React/Vue.js) | 120h |
| Back-end : Node.js/Python/PHP | 130h |
| Bases de données et API | 90h |
| Développement mobile | 80h |
| Projet final et stage | 400h |

## Informations pratiques
